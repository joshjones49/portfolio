## Run Locally

```bash
git clone https://github.com/joshjones49/portfolio.git
cd portfolio
npm install
npm run dev
```

Other scripts:

```bash
npm run build    # production build in dist/
npm run preview  # preview the production build
npm run lint     # run ESLint
```

## Deployment

Deployed on [Vercel](https://vercel.com/) using the Vite preset (build command `npm run build`, output directory `dist`).
